# Synthetic Data Model

## Team signal

```text
TeamSignal
├── id, name, programId
├── lead, focus
├── metrics
│   ├── outcomes
│   ├── predictability
│   ├── quality
│   ├── reliability
│   ├── security
│   └── sustainability
├── evidence freshness
├── governance-rule flags
├── work in progress
├── unplanned work
└── trend
```

## Program

Each program contains an outcome statement, target date, illustrative investment, and the teams contributing to it.

## Constraint

A constraint records type, demand, capacity, downstream exposure, the affected program, and the recommended leadership move.

## Decision

A decision records urgency, title, accountable forum or owner, expected impact, visible evidence, and program scope.

## Data policy

All names, programs, dates, investments, scores, and narratives are fictional. The repository contains no employer exports, credentials, proprietary schemas, or production telemetry.
